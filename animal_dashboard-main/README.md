# 🐾 动物百科实时监控看板 (Animal Encyclopedia Dashboard)

本项目是基于 Streamlit + Pandas + Plotly 开发的交互式数据看板，用于动物百科科普与濒危状况监控。

## ✨ 核心功能
- **数据概览**：核心指标卡片展示。
- **维度统计**：纲目对比、濒危等级占比、栖息地分布。
- **多维分析**：体重与寿命关系散点图、寿命 Top 5 排行榜。
- **全局联动**：支持搜索、按分类/濒危等级筛选，所有图表实时同步。
- **进阶特性**：实时数据刷新、阈值预警闪烁、自动轮播。
- **双主题切换**：自然科普绿主题 vs 科技风动态暗黑大屏模式。

## 🚀 如何运行
1. 安装依赖：`pip install -r requirements.txt`
2. 运行应用：`streamlit run app.py`
